# Support

This repository is commercetools Labs reference code. It is published under the MIT license and is **not supported**:
there is no service level, no guaranteed maintenance and no compatibility promise between versions.

- Review, test and operate the code as your own before using it in a project.
- Issues and pull requests are welcome, but there is no commitment to answer or merge them.
- For questions about commercetools products themselves, use your regular commercetools support channel; it does not
  cover this repository.
